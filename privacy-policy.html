Clips Automation is a personal upload script, not a public service. It runs on one person's own computer and publishes that same person's own video clips to their own YouTube and TikTok accounts. This page explains, plainly, what data the script touches and what it does with it.

01What this is

Clips Automation is a local Python program. It is not a hosted website, it does not have visitors, and it does not create accounts for anyone. The only person who operates it is the developer who installed it, uploading video files they made themselves to social accounts they own.

02Data it reads

To do its job, the script reads, from files stored on the operator's own computer:

  • Video clip files (.mp4) the operator placed in a local folder.
  • A spreadsheet (schedule.csv) the operator filled in themselves: a title, description, hashtags, publish time and privacy level for each clip.
  • OAuth credentials issued by Google and TikTok for the operator's own accounts (see §05).

No other person's data — names, emails, viewing habits, comments — is collected, scraped, or processed at any point.

03Where data goes

Each clip and its metadata is sent, over an encrypted connection, straight to two destinations and nowhere else:

YouTube Data API v3
operated by Google LLC, to publish the video to the operator's own channel.
TikTok Content Posting API
operated by TikTok Inc., to publish the video to the operator's own TikTok account.

The script itself has no server, no database, and no analytics — it does not phone home to the developer of this script or anyone else.

04Storage & retention

Everything — video files, the metadata spreadsheet, logs, and access tokens — stays on the operator's own hard drive, in the folder they installed the script into. Deleting that folder deletes all of it. Nothing is copied to any server the developer of this tool controls.

05OAuth tokens

Logging in once grants the script a token scoped only to upload video permissions — it cannot read messages, contacts, analytics, or anything outside posting content. Tokens are stored locally in plain files (youtube_token.json, tiktok_token.json) and used only to authenticate the operator's own uploads.

06Third parties

Data is never sold, rented, or shared with advertisers, analytics vendors, or any party beyond the YouTube and TikTok APIs the clip is being published through — because publishing the clip is the entire purpose of the script.

07Your controls

Because the operator and the "user" are the same person, control is direct:

  • Revoke access any time from Google Account permissions or TikTok's app settings.
  • Delete everything by deleting the local project folder — no server-side copy remains.
  • Stop uploads by ending the scheduled task described in the project's README.

08Contact

Questions about this policy or this app's use of the TikTok / YouTube APIs can be sent to clipsdetodo776@gmail.com.
